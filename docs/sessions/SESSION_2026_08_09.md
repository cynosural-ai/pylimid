## Next: solve the influence diagram — exact bucket elimination first

The graph now represents decisions and utilities, but nothing computes an optimal policy yet. The solver is the next milestone, planned as two reviewable PRs.

### PR A — the solver core (`inference/id/`)

New subpackage, numpy-only, consuming a `Snapshot`:

- **`bucket_elim.py`** — the exact discrete policy solver, the influence-diagram counterpart to VE:
  1. **Factor build** — one CPT factor per chance node, plus one utility factor per utility node (enumerate parent assignments, call `values(**parents)`), forming the expected-utility objective.
  2. **Reverse-topological elimination** (sinks → roots, i.e. the Snapshot's order reversed). For each variable: multiply all factors mentioning it; **chance → sum out**; **decision → max out**, recording the `argmax` per information-set assignment — that is the policy.
  3. **Return** a `Policy` (decision → `{info_assignment: action}`) plus the max expected utility and per-action EU (what makes the tests hand-verifiable).
- **`arc_reversal.py`** — the ADR's internal helper for `bucket_elim`. v0 (single decision / independent info sets) may not need it yet; it is what unlocks the general non-nested-info-set LIMID case.

### PR B — engine wiring

- **`engine.py`** — public `solve(diagram)` verb with `_choose_solver` dispatch (bucket_elim when all-categorical + tractable; numpyro intervention-scan otherwise). `infer()` gains `policy=` with all-or-nothing binding; unbound decisions raise `InferenceError`; bound decisions clamp → the diagram collapses to a BN → existing VE / NumPyro paths run unchanged.
- Policy is a solve-time object, not stored on the `DecisionNode` (settled in the previous session plan).

### Shared CPT helper

`bucket_elim` needs the CPT-building logic VE owns privately (`_cpt` / `_extract_probs` in `ve/elim.py`). Promote it to a shared helper (e.g. `inference/_cpt.py`) alongside `_factor`, so both engines use it and `id/` never imports from `ve/`.

### Test plan

- `solve()` on a hand-computable single-decision ID — assert exact optimal action + EU.
- `solve()` on a two-decision LIMID with independent information sets.
- `infer(..., policy=...)` fully bound → matches VE on the collapsed BN.
- `infer()` with an unbound decision raises `InferenceError`.
