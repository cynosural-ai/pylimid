API reference
=============

This reference describes the public classes, functions and methods in PyLIMID. For explanations and examples, see the :doc:`user guide <../user_guide/building_a_diagram>`.

- :doc:`Inference and solving <pylimid>`: `infer`, `solve`, their results and errors.
- :doc:`Building diagrams <graph>`: `ChanceNode`, `DecisionNode`, `UtilityNode`, `InfluenceDiagram` and validation results.
- :doc:`Policy families and rules <policy>`: trainable families, fitted decision rules and policy types.
